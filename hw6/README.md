ОПИСАНИЕ ПРОЕКТА

Данный проект посвящен комплексному анализу датасета Wholesale Customers (клиенты оптовой торговли) с использованием методов машинного обучения. 

Цели работы:
1. Сегментация клиентов - разделение на группы со схожими паттернами покупок (6 алгоритмов)
2. Поиск аномалий - выявление необычных клиентов (5 методов)
3. Анализ важности признаков - определение ключевых факторов сегментации
4. Визуализация результатов - графики, тепловые карты, PCA проекции
5. Сравнение алгоритмов - объективная оценка качества

Датасет
- Источник: UCI Machine Learning Repository
- Записи: 440 клиентов (после очистки: 332)
- Признаки: 8 (6 числовых, 2 категориальных)

6.2 Ключевые факторы разделения

Detergents_Paper (40.3%) - главный признак, разделяющий клиентов:
- Низкие значения  > Рестораны/кафе (не закупают бытовую химию)
- Высокие значения > Розница (торгуют бытовой химией)

6.3 Аномалии - особые клиенты

37 аномальных клиентов (11%) требуют внимания:
- Экстремально высокие траты в одной категории
- Необычные комбинации покупок
- Потенциальные ошибки ввода данных
- Возможно, крупные оптовики или сетевые магазины
