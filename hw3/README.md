В работе произведено:
1.нахождение и распаковка датасета формата .zip;
2.Подключение к SQLite базе данных и загрузка данных;
3.Формирование sql-запросов для извлечения данных;
4.Видуализация данных:
- количество внедренных роботов по отраслям;
- динамика роста производительности и внедрения роботов;
- динамика сокращения численности персонала и внедрения роботов;
- тепловая карта экономии по отраслям и годам;
- матрица корреляции параметров;
- связь между сокращением персонала и ростом производительности;
- среднее время обучения по отраслям;
- влияние обучения на рост производительности;
- сравнение отраслей по экономии денежных средств;
- динамика роста показателей за базовый год.

Ссылка на датает:https://www.kaggle.com/datasets/kennedywanakacha/industrial-robotics-and-automation-dataset
Этот набор данных позволяет получить представление о внедрении робототехники и автома-
тизации на основе искусственного интеллекта в различных отраслях за несколько лет.
Он включает такие показатели, как общее количество внедренных роботов, повышение произво-
дительности, сокращение рабочих мест, экономия затрат и количество часов обучения, необхо-
димых для развития навыков в результате автоматизации. Эти данные могут помочь проанализи-
ровать социально-экономическое воздействие робототехники в производстве, здравоохранении, 
логистике и других секторах.
