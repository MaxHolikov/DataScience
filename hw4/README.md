В работе произведено: 
1.нахождение и распаковка датасета формата .zip; 
2.анализ датасета на наличие пропусков;
3.приведение категориальных признаков датасета к числовым;
4.удаление слабокоррелируемых параметров для повышения качества метрики
5.проверка данных на различных классификаторах:
- классификатор градиентного бустинга
- Классификатор Extra Trees.
- Классификатор AdaBoost.	
- Классификатор K-Nearest Neighbors.
- Классификатор дерева решений.

Для данного датасета и приминяемости вышеописанных классификаторов нормализация и скалированние данных не приводят к увеличению метрики.
